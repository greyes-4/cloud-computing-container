Step 02: Reflection

In this step, I learned how Docker works and how to create and manage a Linux container on my Windows computer. I was able to verify that Docker was installed correctly, run the hello-world container, and create an Ubuntu container. I also learned the difference between stopping and removing a container by using commands such as docker ps -a, docker stop, and docker rm. Running cat /etc/os-release helped me confirm that I was actually working inside an Ubuntu Linux environment even though my computer runs Windows. Overall, this step helped me understand how Docker allows me to run an isolated Linux environment without needing a separate physical computer or traditional virtual machine.
